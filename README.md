# HugEtsy

Landing page for HugEtsy, a tool that turns resale items into Etsy listings.

A Jekyll site built and hosted by GitHub Pages. Push to `main` and the site rebuilds in a minute or two.

- `_config.yml`: site title, description, URL
- `_layouts/default.html`: page shell (head, header, footer)
- `index.html`: landing page content
- `_data/features.yml`, `_data/steps.yml`: the feature and how-it-works cards
- `assets/css/style.css`: styles

Not affiliated with Etsy, Inc.
